🔧 How It Works

How Does This Project Extract Information?

A step-by-step breakdown of the data extraction and calculation pipeline.

🧠 The Algebra That Powers Everything

N = E ÷ (P × S)
E
Daily Energy Consumption — Total kWh used by the household per day. Extracted from user input.
P
Panel Output — Rated wattage of one solar panel in kW (default: 0.4kW = 400W).
S
Sunlight Hours — Average peak sunlight hours per day (default: 5 hours).
N
Panels Required — Result of E ÷ (P × S), rounded up to next whole number.

Information Extraction Pipeline

1️⃣ User Input Extraction

The system captures daily kWh consumption directly from the user. Alternatively, it can accept individual appliance wattages and usage hours, then sum them to derive total daily consumption.

2️⃣ Parameter Assignment

Default values are loaded for panel output (0.4 kW) and sunlight hours (5h). Users can override these. The system validates all inputs to prevent division-by-zero or negative results.

3️⃣ Algebraic Computation

The core formula N = E ÷ (P × S) is evaluated. The result is always rounded UP using Math.ceil() because you can't install a fraction of a panel.

4️⃣ Cost Derivation

Annual consumption = daily kWh × 365. Grid cost = consumption × ₹8/kWh tariff. Solar cost = panels × ₹3,500/year maintenance. Savings = grid cost − solar cost.

5️⃣ Environmental Calculation

CO₂ reduction = annual consumption × 0.82 kg/kWh (Indian grid emission factor). This shows the exact environmental benefit of switching to solar.

6️⃣ Data Persistence

Every calculation is timestamped and stored with the user's ID. This creates a history trail that powers the analytics, graphs, and prediction features.

📊 Example Walkthrough

// User Input:
E = 10 kWh (daily consumption)
P = 0.4 kW (panel output)
S = 5 hours (sunlight)
// Calculation:
N = 10 ÷ (0.4 × 5)
N = 10 ÷ 2
N = 5 panels
// Derived:
Annual Cost = 10 × 365 × ₹8 = ₹29,200
Solar Cost = 5 × ₹3,500 = ₹17,500
Savings = ₹29,200 − ₹17,500 = ₹11,700/year
CO₂ Reduced = 3,650 × 0.82 = 2,993 kg CO₂
